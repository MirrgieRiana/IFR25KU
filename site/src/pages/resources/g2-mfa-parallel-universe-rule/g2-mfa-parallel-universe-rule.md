{% paper_title %}並行宇宙ルール{% endpaper_title %}

並行宇宙ルールの経緯は、次の2枚の「地球」で書かれた記事によって導入されます。

{% paper_link "/2026/09/22/g2-mfa-mail-from-space.html" "G2-MFA　宇宙からのメール解読される 外命研が発表" %}
{% paper_link "/2026/09/22/g2-mfa-observation-satellite.html" "G2-MFA　外命研 文献探しに並行世界に 観測衛星打ち上げ" %}

かいつまんで説明すると、

- 宇宙から謎のメッセージを受信したよ
- 次のメッセージが送られてくるまで通常4か月もかかるよ
- 違うメッセージが送信されていた並行宇宙から取って来ればいっぱい見れるよ

といったイメージです。

{% paper_figure "/assets/images/g2-mfa-parallel-universe-rule/parallel-universe-branching.png" %}

この設定により、次のようなことが起こります。

- 複数の文献間で生じた矛盾を、世界観的な意味を持って解釈できる。
- 執筆者それぞれが自分の並行宇宙を持って創作できる。
- 注目したい文献以外の文献で追加された設定をすべて無視できる。

{% paper_figure "/assets/images/g2-mfa-parallel-universe-rule/document-reference-graph.png" %}

並行宇宙ルールは、MirageFairy Server公式以外の、ファンの手による二次創作的な作品が簡単に作れることを目指して作られました。

{% paper_section %}MFAリポジトリ{% endpaper_section %}

MFAリポジトリは、国立地球外生命体研究機構（外命研）が収集した文献集です。

MFAリポジトリに関する詳しい経緯は、「地球側の文献」を参照してください。

※本文中で言及されている単位は、地球における単位系に換算したものです。
