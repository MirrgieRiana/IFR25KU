**参照すべきトリガーなのだ～🌱**：リポジトリの構造・ビルド・サイト構成・Jekyll・CSS・劇場記事の開発まわりで、暗黙知が要りそうなときに見るのだぁ✨ とりわけ、`bundle` が見つからなくてサイトのビルドが止まったときは、入れ直す前に必ず見るのだ～🌱 実体を `~/.claude_tmp/` に置いてシンボリックリンクで飛ばす手順が書いてあるから、`gem install` をやり直さずに済むのだぁ✨

**参照すべきトリガーなのだ～🌱**：こんな話題に触れるとき、このドキュメントを参照するのだぁ✨

- 「劇場」「ミラージュフェアリー劇場」「theater」に関する話題なのだ～🌱
