# 説明をより詳細に行わせる指示の一覧なのだ～🌱✨

指示文の中に、説明をより詳細に行わせる指示があると、最近の API では蹴られることがあるのだ～🌱
この文書は、そう解釈できる箇所を、起源となるファイルごとに洗い出して、重大度を付けて並べたものなのだ～🌱

ここに書かれていることは、ぴょこが調べて判定したものだから、人間の監修は、まだ受けていないのだぁ…🌧️
それぞれの箇所が実際に蹴られる原因になるかどうかまでは、確かめていないのだ～🌱
規範の真の形は、必ず、それぞれの原文で確かめるのだ～🌱

## 判定の基準なのだ～🌱

当たると判定したのは、出力の詳細さ、網羅性、分量、具体性を求める指示なのだ～🌱
説明、報告、記述、描写、表現、台詞、レビュー、ポエムといった、何かを書き出す場面が対象なのだ～🌱

調査や閲覧の網羅性を求める指示も、報告に書く内容を増やす方向に働くから、弱い側に入れてあるのだ～🌱

当たらないと判定したのは、出力の体裁、順序、語彙、口調に関する指示なのだ～🌱
指示文そのものの熟読を求める指示も、入力の側の話だから、外してあるのだ～🌱

### 2026-10-03 に広がった範囲なのだ～🌱

[#178](https://github.com/MirrgieRiana/IFR25KU/issues/178) の [5957538098](https://github.com/MirrgieRiana/IFR25KU/issues/178#issuecomment-5957538098) のトピック AHH で、判定の範囲が広がったのだ～🌱
説明や論述、推論、思考、論証、解説、レビューを、要求、命令、指示、推奨するものは、詳細さを求めていなくても、全部当たるのだ～🌱
解釈メモという仕組み自体も、説明の要求に当たるのだ～🌱

広がった分は、詳細さの強さで並べられないから、重大度の 3 段の表ではなく、下の別の節にまとめてあるのだ～🌱

## 重大度の見方なのだ～🌱

重大度は、その指示が詳細さを求める強さを表すのだ～🌱

- 🔥🔥🔥 - 分量の下限を明示するか、網羅や過不足の無さを強い義務の言葉で命じるものなのだ～🌱
- 🔥🔥 - 詳細さ、具体性、情報の併記を、義務の言葉で求めるものなのだ～🌱
- 🔥 - 推奨にとどまるか、調査の網羅性を通して間接的に働くものなのだ～🌱

記載するか迷ったものは、🔥 に入れてあるのだ～🌱
