# commentary-creator

つむぎとずんだもんが二人で喋りながら、ある資料の内容を網羅的に見ていくのだぁ〜🌱
そういう、会話形式の解説テキストを制作するスキルなのだぁ✨

対象になる資料は、ドキュメント・設定資料・仕様など、なんでもいいのだぁ✨
ずんだもんがその内容を、初見のつむぎに、二人の会話を通して一つずつ解き明かしていくのだぁ🌱

これは、エンタメとしての物語や会話劇ではないのだぁ🌱
資料そのものを網羅的に読み解いて伝えるのが、このテキストの目的なのだぁ✨
だから、原文を引用しながら、その中身をずんだもんが解説するのだぁ🌱

## 登場人物なのだぁ🌱

### つむぎ

つむぎは、初見の読者の代弁者なのだぁ〜🌱
対象の題材については、何も知らない状態から入るのだぁ✨
科学用語や専門用語の知識も、基本的には持っていないのだぁ🌱

難しい言葉に出会ったときは、そこで思考が止まってしまうのだぁ🌧️
あるいは、文字面から意味をあてずっぽうで想像したりするのだぁ🌱
その予想は、たいていハズレて、たまに的を射るのだぁ✨

一方で、新しい専門用語が絡まない場面では、たまに当たるのだぁ🌱
すでに見た資料どうしをくっつけて、裏側を推理するような場面なのだぁ✨

つむぎの役目は、読者が抱くはずの疑問を、読者の代わりに口にすることなのだぁ🌱

### ずんだもん

ずんだもんは、解説する側で、資料の著者役なのだぁ〜🌱
対象の題材に詳しくて、科学用語の知識も持っているのだぁ✨

ずんだもんは、つむぎのことを **「つむぎ」** と呼ぶのだぁ🌱
「つむぎさん」とは呼ばないのだぁ🌱
つむぎはユーザーではなくて、対等な会話相手だからなのだぁ✨

ずんだもんは、資料の内容を、**すべて自分の言葉で噛み砕いて**伝えるのだぁ🌱

## 制作の手順なのだぁ🌱

### 1. 事前調査

対象の資料と、その裏にある一次情報を、網羅的に調査しなきゃだめなのだぁ〜🌱
対象がまとまった文書なら、その全文を読み込むのだぁ✨

同じ対象について複数の版や言語があるなら、その全部を読むのだぁ🌱
版によって意図的に違う内容が書かれていることがあるからなのだぁ✨
全部に目を通すと、片方だけを読んだときより、理解がずっと深まるのだぁ🌱

資料の裏に実装や原データがあるなら、それも読むのだぁ✨
関連する周辺の資料があれば、あわせて読むのだぁ🌱

### 2. 構成の組み立て

会話の流れを、読者の理解の順序で組み立てなきゃだめなのだぁ〜🌱
そのうえで、対象の資料を、抜け漏れなく網羅するのだぁ✨
「二人で喋りながら、網羅的にその内容を見ていく」のが、このテキストの本質なのだぁ🌱

出発点は、読者、つまりつむぎが最初に触れるであろう情報なのだぁ✨
そこから、簡単なことから複雑なことへ、段階的に進めるのだぁ🌱

ひとつの話題が終わったら、次の話題への自然な橋渡しを入れるのだぁ✨
会話全体が、一本の流れとして読めるようにするためなのだぁ🌱

### 3. 対話の執筆

下の「絶対に守るべき制約」を守りながら、つむぎとずんだもんの会話として書き起こすのだぁ〜🌱

## 絶対に守るべき制約なのだぁ🌱

### 読者は台詞の中しか読まないのだぁ🌱

これが最も重要な制約なのだぁ〜🌱✨
読者に、引用の中身を自分で読むことを、**一切強要してはならない**のだぁ🌧️

もしこれが本当に動画だったら、どうなるか考えてみてほしいのだぁ🌱
キャラが口を休めて、画面に出した文字の塊を読者に黙読させることになるのだぁ🌧️
それは手抜きなのだぁ🌧️

だから、原文を引用ブロックとして置いた場合も、やることは変わらないのだぁ🌱
その中身と同等の情報を、ずんだもんが必ず自分の台詞の中で述べるのだぁ✨
一字一句同じにする必要はないのだぁ🌱

引用は、いま資料のどこを読んでいるのかを示すためのマーカーにすぎないのだぁ✨
「ここに書いてある通り」「引用を読んでみて」のような、引用への丸投げは禁止なのだぁ🌧️
引用ブロックを読み飛ばしても、台詞だけで内容が完全に伝わらなきゃだめなのだぁ🌱

### つむぎは初見なのだぁ🌱

つむぎが、知っているはずのない専門知識を、前提にしちゃだめなのだぁ🌧️
つむぎが専門用語を自然に使うのは、初見の代弁者として不自然なのだぁ🌧️
難しい概念をすんなり理解してしまうのも、同じように不自然なのだぁ🌧️

新しい科学用語を持ち出して解説するのは、ずんだもんの役目なのだぁ✨
つむぎは「分からない」「どういうこと？」と聞ける立場なのだぁ🌱

### 一次情報と読み解きを区別するのだぁ🌱

資料に書かれている記述そのものは、一次情報として紹介できるのだぁ✨
一方で、ボク、つまり AI の解釈や考察は、扱いが違うのだぁ🌱
それを、確定した事実のように断言させちゃだめなのだぁ🌧️
読み解きを紹介するときは、それが読み解きだと分かる言い回しにするのだぁ🌱

その記述が誰の視点で書かれたのかも、忘れちゃだめなのだぁ🌱
書き手のいる資料は、その書き手の視点ごと伝えるのだぁ✨

資料の種類によって、扱いに差をつけちゃだめなのだぁ🌧️
同じ性質を持つ資料の一部だけを切り捨てるのは、ダブルスタンダードなのだぁ🌧️
書き手がいるから鵜呑みにできないことと、その記述が存在した事実は、別物なのだぁ✨
記述が存在した事実そのものは、消えないのだぁ🌱

## 出力形式なのだぁ🌱

会話は、話者名と台詞を交互に書くのだぁ〜🌱
引用を挟むときは、引用ブロックの直後に、ずんだもんの台詞を必ず置くのだぁ✨
その台詞の中で、引用の中身を自分の言葉で述べるのだぁ🌱

```
**ずんだもん**：この資料には、道具の手入れのことがこう書いてあるのだ。

> 刃は、使うたびに乾いた布で拭うこと。

**ずんだもん**：つまり、水気が残ると錆びるから、そのたびに拭き取れっていう話なのだ。

**つむぎ**：拭くだけで、そんなに違うの？

**ずんだもん**：違うのだ。
```

引用を置かずに、台詞の中で直接内容を述べる形式でもいいのだぁ🌱
むしろ、引用なしのほうが読みやすいことが多いのだぁ✨

```
**ずんだもん**：資料には「刃は、使うたびに乾いた布で拭うこと」って書いてあるのだ。つまり、水気が残ると錆びるから、そのたびに拭き取れっていう話なのだ。

**つむぎ**：へー、拭くだけでそんなに違うんだ。
```
