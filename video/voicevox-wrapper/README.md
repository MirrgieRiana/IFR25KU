# voicevox-wrapper なのだ～🌱

合成のリクエストを並べた jsonl から、VOICEVOX ENGINE で行ごとの音声を合成する、汎用のラッパーなのだ～🌱

## 使い方なのだ～🌱

```sh
bash synth.sh <requests.jsonl> <outDir>
```

引数のパスは、呼び出し元のカレントディレクトリを基準に解決するのだ～🌱

- `requests.jsonl` は、1 個の音声のリクエストの JSON オブジェクトを、1 行に 1 個ずつ並べたファイルなのだ～🌱
- `outDir` は、`00000.wav` から始まる連番の音声と、同じ番号の JSON の出力先のディレクトリなのだ～🌱

引数が 2 個でないときは、使い方を出して、終了コード 1 で終わるのだ～🌱
`outDir` が、空のディレクトリでも、存在しないパスでもないときは、エラーを出して、終了コード 1 で終わるのだ～🌱
リクエストの jsonl の空行は、無視するのだ～🌱
VOICEVOX ENGINE が失敗を返したときは、エラーを出して、終了コード 1 で終わるのだ～🌱

## リクエストの行の形なのだ～🌱

各行のルートオブジェクトは、次のキーを持つのだ～🌱

| キー | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `speaker` | 整数 | 必須 | VOICEVOX のスタイル ID なのだ～🌱 |
| `text` | 文字列 | 必須 | 読み上げる文章なのだ～🌱 |
| `kana` | 文字列 | 任意 | 読みを指定する、AquesTalk 風記法のカナなのだ～🌱 |
| `query` | オブジェクト | 任意 | 合成の前に、音声合成用のクエリへ上書きするキーと値なのだ～🌱 |

形が違う行があるときは、行番号付きのエラーを出して、終了コード 1 で終わるのだ～🌱

```json
{"speaker": 3, "text": "こんにちは", "kana": "コンニチワ'", "query": {"speedScale": 1.1}}
```

## 合成の流れなのだ～🌱

ラッパーは、リクエストの jsonl を先頭から 1 行ずつ、次の順に合成するのだ～🌱

1. `text` から、`/audio_query` で音声合成用のクエリを作るのだ～🌱
2. `kana` があれば、`/accent_phrases` で `kana` を読み直して、クエリのアクセント句を差し替えるのだ～🌱
3. `query` があれば、そのキーと値で、クエリを上書きするのだ～🌱
4. そのクエリで、`/synthesis` から音声を合成するのだ～🌱

`kana` が無い行では、アクセント句は、`text` から VOICEVOX ENGINE が推定したままなのだ～🌱

## 出力なのだ～🌱

行ごとに、空行を除いて 0 から数えた行の順番の連番で、次の 2 個のファイルを書くのだ～🌱

- `00000.wav` は、合成した音声なのだ～🌱
- `00000.json` は、合成に使ったクエリなのだ～🌱

クエリの JSON の `kana` は、`kana` を指定した行ではその文字列で、それ以外の行では VOICEVOX ENGINE が付けたものなのだ～🌱
口パクの区間のような、音声の中の時刻は、このクエリから計算できるのだ～🌱

## 環境変数なのだ～🌱

| 変数 | 既定 | 説明 |
| --- | --- | --- |
| `VOICEVOX_HOST` | `http://127.0.0.1:50021` | VOICEVOX ENGINE の URL なのだ～🌱 |

VOICEVOX ENGINE は、先に起動しておくのだ～🌱
Node は、`fetch` を持つ 18 以降が要るのだ～🌱
