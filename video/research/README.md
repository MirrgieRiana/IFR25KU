# 紹介動画の調査の記録なのだ～🌱

このディレクトリは、紹介動画の台本を組み立てるまでに調べたことの記録なのだ～🌱
元は [#630](https://github.com/MirrgieRiana/IFR25KU/pull/630) のコメントとして投稿されていたものを、ファイルへ移したものなのだ～🌱

台本そのものは [scripts/](../scripts/) にあって、動画を作るときのルールは [RULES.md](../RULES.md) にあるのだ～🌱

| ファイル | 中身 |
| --- | --- |
| [script-sources.md](script-sources.md) | 既存の台本の資料と、そこから分かった構成と、台詞の長さの基準なのだ～🌱 |
| [policy.md](policy.md) | 司令部で定められた、紹介動画の方針なのだ～🌱 |
| [hook-candidates.md](hook-candidates.md) | 開幕に使えそうなキャッチーな情報の候補なのだ～🌱 |
| [existing-videos.md](existing-videos.md) | 既存の動画のパターンを分析した、手順と標本の全体なのだ～🌱 |
| [structure-draft.md](structure-draft.md) | 2 個目の台本の骨格を組んだときの記録なのだ～🌱 |
| [footage-survey.md](footage-survey.md) | 既存の動画の映像を実際に見て、録画が要るかを測った記録なのだ～🌱 |
