## 2. YouTube の字幕の取得なのだ～🌱

既存の動画の構成を分析するために、字幕が取れるかを実測したのだ～🌱
3 個の方法を試したのだ～🌱

| 方法 | 第三者の動画 | 認証 | 実測の結果 |
| --- | --- | --- | --- |
| YouTube Data API v3 の `captions.download` | 不可 | OAuth 2.0 | 原理的に不可。動画の編集権限が必須なのだ～🌱 |
| `youtube-transcript-api` | 可能 | 不要 | 成功。489 セグメントが取れたのだ～🌱 |
| `yt-dlp --write-auto-sub` | 可能 | 不要 | 成功。`.vtt` が取れたのだ～🌱 |

後ろの 2 個は、どちらも実際に動いたのだ～🌱
ただし、どれも自動音声認識に基づくから、誤変換が一定量混ざるのだ～🌱
細かい語彙は当てにならないけれど、構成のパターンを見るには足りるのだ～🌱

## 6. 直した誤りなのだ～🌱

琥珀色の原生林の説明で、1 個の誤りがあったのだ～🌱

最初の案では、このバイオームの中が「石化した樹脂の地帯」と「まばらなジャングル」に分かれる、と書いていたのだ～🌱
でも、`OldGrowthAmberForest.kt` の 220 行目からの地表のルールを読んだら、ノイズで分かれるのは、**石化した樹脂の地帯** と、**粗い土やポドゾルの地帯** だったのだ～🌱

「まばらなジャングル」は、このバイオームが **上書きする対象** の 1 個なのだ～🌱
255 行目で、ジャングルとまばらなジャングルと竹林を上書きしているのだ～🌱
バイオームの中の地帯ではないのだ～🌱
だから、台本の方を直したのだ～🌱
